# 지우개 따먹기 (1단계 손맛 시안)

학교 책상 위에서 지우개를 번갈아 튕겨 상대 지우개 위에 올라타면 이기는 3D 게임. Three.js + Rapier 3D.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 연다. 새로 고침할 때마다 소스를 다시 묶는다.
`npm run build`만 하면 `dist/index.html` 한 파일이 나오고, 이 파일은 서버 없이 더블클릭으로도 열린다.

## 조작

| 조작 | 키 | 화면 버튼 |
|---|---|---|
| 방향 조절 | ← → 또는 A D | ◀ ▶ |
| 게이지 시작 / 튕기기 | Space | 게이지 시작 / 튕기기! |
| 다시 시작 | R | 결과 창의 다시 시작 |

한 화면에서 1P(파랑)와 2P(주황)가 번갈아 튕긴다. 게이지가 움직이는 동안 방향은 고정된다.

## 규칙

- 지우개가 멈췄을 때 상대 지우개에 실제로 받쳐진 채 0.8초를 버티면 위에 있는 쪽이 이긴다(누구 차례였는지는 상관없다).
- 책상 아래로 떨어지면 떨어진 쪽이 진다. 둘 다 떨어지면 무승부.
- 승패가 없으면 둘 다 멈춘 뒤 차례가 넘어간다.

## 튕기기를 구현한 방식

- 단위: 1 = 10cm. 지우개는 0.5 × 0.1 × 0.25(길이 × 두께 × 폭), 질량 1. 물리는 1/120초 고정 간격, CCD 켬.
- 충격 한 번을 무게중심에서 벗어난 점에 준다. 점은 "발사 방향 기준 뒤쪽(`hitBack`), 아래쪽(`hitHeight`)"이고, 충격은 수평 성분 + 위쪽 성분(`vAssist`)이다. 지우개의 지금 자세에서 그 방향으로 차지하는 길이를 재서 점을 잡으므로 뒤집히거나 서 있어도 계산이 같다.
- 회전은 그 충격의 토크(r × J)에서 나온다. 기본값에서는 "아래쪽을 수평으로 민 효과"가 "뒤쪽을 위로 든 효과"보다 커서 앞이 들린다(패널의 `앞 들림 토크`가 양수). `spinAssist`는 같은 축으로 더하는 회전 충격이다.
- 파워는 `impulse × 게이지^powerCurve`. 궤적을 정해 두거나 상대 쪽으로 끌어당기는 보정은 없다.

## 걸침과 낙하 판정

- 걸침: Rapier의 두 지우개 사이 접촉 매니폴드에서 (1) 실제로 닿은 접촉점이 있고 (2) 접촉 법선의 세로 성분이 0.6 이상이며 (3) 접촉점이 한쪽 중심보다 아래, 다른 쪽 중심보다 위에 있을 때 "받쳐짐"으로 본다. 이 상태와 두 지우개의 저속 상태가 `perchHold`초 동안 끊기지 않아야 승리. 끊기면 타이머를 0으로 되돌린다.
- 낙하: 중심 높이가 책상 윗면 아래 10cm(-1.0)보다 내려가면 낙하. 일부만 책상 밖으로 나온 것은 낙하가 아니다. 한쪽이 떨어지면 남은 쪽이 책상 위에서 멈출 때까지 기다린 뒤 결과를 확정하고, 그 사이 남은 쪽도 떨어지면 무승부.
- 안정: 선속도·각속도가 기준 아래인 상태가 `stableHold`초(시뮬레이션 시간) 이어지면 멈춘 것으로 본다. 10초가 넘으면 기준을 3배로 풀어 미세한 떨림을 넘기고, 25초가 넘으면 "이번 차례 다시 하기" 버튼을 띄운다.

## 개발자 패널

오른쪽 위 "개발자 패널". 설정값은 편집 즉시 저장되지만 **다음 발사부터** 적용되고, 지금 시뮬레이션에 적용된 값과 다르면 항목에 표시된다.

- 설정: 기본값으로 / JSON 복사 / JSON 내려받기 / 가져오기(붙여 넣기 또는 파일). 범위를 벗어나거나 빠진 값은 이유와 함께 거부한다.
- 발사 재현: 방향(도)·파워(%)를 숫자로 넣어 발사, 발사 전 상태 저장·복원, 같은 조건으로 다시 발사, 성공 재현 프리셋.
- 성공 재현 프리셋: 기본 배치, 1P, 방향 0도, 파워 55%. "프리셋 바로 발사"를 누르면 1P가 2P 위에 올라타 승리한다.
- 지금 상태: 게임 상태, 속도, 접촉 여부, 받침 판단, 안정·걸침 유지 시간.

## 손맛을 조정할 때 먼저 바꿀 것

1. `impulse`(발사 충격량): 전체 세기. 올라타는 파워 구간이 게이지의 어디에 오는지를 정한다.
2. `vAssist`(수직 보조): 도약 높이. 낮추면 미끄러져 옆면에 부딪히고, 높이면 넘어가 버린다.
3. `gravity`(중력): 체공 시간과 묵직함. 실제 비율은 약 98이고 지금은 60으로 조금 느리게 잡았다.
4. `friction`(마찰): 착지 후 미끄러짐. 낮추면 올라탔다가 미끄러져 내려온다.
5. `angDamp`·`spinAssist`: 공중 회전량.

바꾼 뒤 `node test/tune.mjs impulse=22 vAssist=0.3`처럼 실행하면 방향·파워별 결과 지도가 나온다.

## 화면 디자인

옛날 교실과 문방구 분위기로 맞췄다. 줄 공책 쪽지(안내), 명찰(차례 표시), 칠판(차례 전환 알림), 30cm 자(파워 게이지, 빨간 빗금은 위험 구간), 색연필 동그라미(걸침 확인), "참 잘했어요" 도장(승리), 공책 표지(시작 화면). 효과음은 파일 없이 코드로 만들고 왼쪽 아래 버튼으로 끈다.
